♻️ Kabadiwala Connect

Fair earnings and traceable e-waste recycling.
A project built for the Smart India Hackathon (SIH).

🔗 Important Links

Live Demo: https://kabadiwala-connect-ready-to-deploy.vercel.app/

GitHub Repository: https://github.com/yashgitofficial/kabadiwala-connect

📖 About The Project

Kabadiwala Connect is a platform dedicated to bringing transparency and fairness to the e-waste recycling sector. It provides traceable e-waste recycling while ensuring fair earnings for waste pickers and scrap dealers.

🛠️ Tech Stack

Framework: React 18

Language: TypeScript

Build Tool: Vite

Styling: Tailwind CSS

Icons: Lucide React

🚀 Getting Started (Local Development)

To run this project locally on your machine, follow these steps:

Prerequisites

Node.js (LTS version recommended)

npm (comes automatically with Node.js)

Installation

Clone the repository:

git clone https://github.com/yashgitofficial/kabadiwala-connect


Navigate into the project directory:

cd kabadiwala-connect


Install the required dependencies:

npm install


Running the App

Start the local development server:

npm run dev


Open your browser and visit http://localhost:5173/ to view the application.

🌍 Deployment

This project is a ready-to-deploy Vite + React single-page application (SPA).

Netlify Deployment (Recommended):
The repository already includes a _redirects file for routing support.

Build Command: npm run build

Publish Directory: dist

Note: The app currently uses mock/local data and browser IndexedDB logic. It does not automatically provision a cloud backend upon deployment.
