# Kabadiwala Connect

Ready-to-deploy Vite + React + TypeScript project generated from the supplied single-file TSX app.

## Deploy to Netlify

If deploying through Netlify's Git integration:
- Build command: `npm run build`
- Publish directory: `dist`

For local testing:
1. Install Node.js (LTS).
2. Run `npm install`
3. Run `npm run dev`

The app currently uses the mock/local data and browser IndexedDB logic contained in the supplied TSX source. It does not automatically become a cloud/Supabase backend just by deploying it.
